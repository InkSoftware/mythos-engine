# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this is

mythos-engine is a C++23 library (not an application) for first-person grid games on SDL3 + OpenGL 4.1 core. Games live in other repos and consume it via `FetchContent`/`add_subdirectory`. See `README.md` for the consumer-facing description.

## Every change updates the docs and the template game (mandatory)

On every change to the engine, before it is done (and before a commit):

1. **Update the Markdown files** the change touches: `CLAUDE.md` (architecture and conventions, so the next session
   knows), `README.md` (what a game gets), `ROADMAP.md` (progress, "done" and what is left), `CREDITS.md` (any new asset or
   third-party code) and `template-game/README.md`. A new module, option, file format, setting, key or tool is never
   undocumented; a doc that describes something that no longer exists is fixed in the same change.
2. **Update `template-game/`** so it still builds, passes its tests and shows the current way of doing things: if the
   change alters an API the template uses, fix the template; if it adds something a new game would want (a module, a
   pattern, a file format), show it there in the smallest honest way (a few lines in `game.cpp` or `main.cpp`, an asset, a
   test in `tests/game_test.cpp`) and say so in its README. The template builds with the engine
   (`MYTHOS_BUILD_TEMPLATE_GAME`), so `cmake --build` and `ctest` already fail when it breaks; run both.
3. Keep `template-game/` formatted and clang-tidy clean like the rest (CI lints it).

## Commands

```sh
cmake -S . -B build
cmake --build build --parallel
ctest --test-dir build --output-on-failure
./build/mythos_engine_tests <name-substring>     # run a subset of tests by name
cmake -S . -B build -DMYTHOS_BUILD_PLATFORM=OFF  # headless: no SDL, no display needed (tests don't need it)
```

- `mythos_pack` (the asset packer, `tools/pack/`) is built with everything else; `mythos_engine_tests` only with `MYTHOS_BUILD_TESTS`.
- Releases (`.github/workflows/release.yml`): pushing a tag `v*` first runs the whole CI (`ci.yml` as a reusable workflow: clang-format, clang-tidy, build and tests) and only then builds `MythosEditor` (portable, `--target mythos_editor_app`; macOS universal) on ubuntu-22.04, macos-15 and windows-2022, uploads each as a workflow artifact and attaches `MythosEditor-<tag>-<platform>` archives (editor plus the engine's `assets/`) to a GitHub release of the tag (a prerelease when the tag has a suffix).
- CI (`.github/workflows/ci.yml`) builds and runs the tests with `MYTHOS_PORTABLE` ON (what ships) on ubuntu-22.04, macos-15 and windows-2022, plus one `MYTHOS_PORTABLE` OFF build on ubuntu-22.04 to keep the system-SDL path covered (the same code on every OS). Each is the oldest supported release of its OS (a binary built there also runs on newer ones); on macOS the portable job is universal (`arm64;x86_64`) and also runs the tests for the x86_64 slice under Rosetta. CI fails on any warning (`MYTHOS_WARNINGS_AS_ERRORS=ON`) and has a `lint` job on macos-15 with Homebrew `llvm@23` that fails on any `clang-format --dry-run --Werror` difference or any `clang-tidy` finding (`--warnings-as-errors='*'`, over `src/`, `tools/`, `tests/`, `template-game/`). Dependabot keeps the actions current (weekly).
- Support floor: Ubuntu 22.04, macOS 15 (`CMAKE_OSX_DEPLOYMENT_TARGET` defaults to 15.0 in `CMakeLists.txt` when the engine is top level), Windows 11. Raise them as vendors drop releases (Ubuntu 22.04 standard support ends about April 2027).
- Defaults to Release when top level. Warnings (`-Wall -Wextra -Wpedantic`, `/W4`) must stay clean, and clang-tidy (`.clang-tidy`: `bugprone-*`, `performance-*`, `clang-analyzer-*` and a few `modernize-*`; verified on LLVM 23) must report nothing: run `clang-tidy -p build <files>` (configure with `-DCMAKE_EXPORT_COMPILE_COMMANDS=ON`; Homebrew's `llvm` is keg-only, so put `$(brew --prefix llvm)/bin` on the PATH). Int to float conversions are allowed on purpose; suppress a deliberate false positive with `NOLINTNEXTLINE(check)` and a reason. `stb_truetype_impl.cpp` and `stb_image_impl.cpp` have warnings suppressed on purpose.
- Code follows the [Google C++ Style Guide](https://google.github.io/styleguide/cppguide.html). `.clang-format` (`BasedOnStyle: Google`, 80 columns, 2 spaces, includes regrouped) is the formatter: run `clang-format -i --style=file` on every `*.cpp` / `*.h` you touch (not `third_party/`). `.editorconfig` pins LF and a final newline (Python tooling keeps 4 spaces).
- Options: `MYTHOS_BUILD_TEMPLATE_GAME` (builds `template-game/`, on when top level), `MYTHOS_BUILD_PLATFORM`, `MYTHOS_BUILD_EDITOR`, `MYTHOS_IMGUI_TAG`, `MYTHOS_BUILD_TESTS`, `MYTHOS_WARNINGS_AS_ERRORS` (off by default; CI turns it on), `MYTHOS_FETCH_SDL`, `MYTHOS_PORTABLE`, `MYTHOS_LTO`, `MYTHOS_SDL_VERSION`.
- Tests are a single home-made harness in `tests/test_main.cpp`: `TEST(name) { CHECK(...); CHECK_EQ(a, b); }`. It links only `mythos_engine`, so tests can never touch SDL/GL code.
- `src/**/*.cpp` files are listed explicitly in `CMakeLists.txt`; add new sources there. Headers are included as `"engine/<folder>/<file>.h"` (the include root is `src/`; folders are listed below).

## Architecture

Two layers, with a hard dependency boundary:

- **`mythos::engine`** (`src/engine/{core,world,audio,data,gfx,ui}/`): pure logic and data. Must not include SDL or OpenGL and must know nothing about any particular game. This is what makes game rules testable headless. Everything is in `namespace mythos`.
- **`mythos::engine_platform`** (`src/engine/platform/*`): the only code that touches SDL3/GL (window, `SceneRenderer`, audio mixer, input, frame clock). GL entry points are loaded at runtime via SDL (`gl_api`), so no GL library is linked.
  - `gl_objects` holds the RAII wrappers (`GlBuffer`, `GlVertexArray`, `GlTexture`, `RenderTarget`, `GlProgram` with cached named uniforms); use them rather than raw `GLuint`s. `Window::Close()` calls `gl::UnloadFunctions()`, so wrappers may outlive the context safely.
  - `SceneRenderer::Render` runs, in order: `ChooseLamps`, `DrawShadows` (lamp and hand cube maps), `DrawSunShadow`, `DrawReflectionProbes`, the mirror view, `DrawMainView` (sky, world, particles, glass into the multisampled target, resolved), `Composite` (`BuildAo`, `BuildBloom`, then the composite shader), `DrawOverlay`. `SceneRenderer` orchestrates the passes (shadows, sky, world into a multisampled target, bloom (a bright pass and a blur at a quarter size, `bloom_blur.frag`, `CameraState::bloom`, on with the Visual effects setting; the Camcorder setting, `CameraState::tape`, is the tape look drawn in `lens_and_fxaa.frag`, HUD included), composite with motion blur / lens / bloom / FXAA, overlay); `TextRenderer` draws the SDF text. World geometry is split into 8-cell chunks at upload (one VAO/VBO per texture, chunks as contiguous ranges) and frustum-culled per frame; neighbouring visible chunks merge into one draw. The overlay `Surface` is uploaded as-is (BGRA, flipped in the quad shader) and skipped when unchanged.
  - Files of the renderer: `scene_renderer.cpp` (passes), `scene_shadows.cpp` (lamp choice, cube maps, the cache), `shaders/vertex/*.vert` and `shaders/fragment/*.frag|glsl` (all GLSL, embedded at build time into a generated source by `cmake/EmbedShaders.cmake`; `scene_shaders.h` declares the strings), and `engine/core/mat4.h` (matrices, frustum and cube-face views, headless and tested).
  - Tone mapping and grading (`gfx/grade.h`, headless and tested; `CameraState::grade`, a `ColorGrade`): exposure, the curve (`Tonemap`: ACES, the default and the original look, filmic or clamp), vignette strength and the sky go through `finishPixel` in `tone_map_and_grain.glsl` (HDR, in the world and sky passes); contrast, saturation, tint and an optional colour lookup table (`SceneRenderer::SetColorLut`, a strip of `size` slices, `IdentityLutStrip`; a 2D texture on unit 2 of the composite pass, two taps across blue, so no 3D textures) are applied in `lens_and_fxaa.frag` after bloom and before the tape look, skipped (`uGradeOn`) when they change nothing. The default grade renders pixel-identically to before; `Sanitize` clamps what a game gives. There is no player setting for it: it is the game's look, per level.
  - Camera feel and tweens (headless, tested): `core/tween.h` has `Ease` / `ApplyEase` (12 curves, exact at 0 and 1), `Tween<T>` (float, double, `Vec2`, `Vec3`; delay, `Retarget`, driven by `Update(dt)`, no clock inside) and `Sequence` (wait, tween into a callback, call; time left over carries into the next step). `world/camera_fx.h` has `CameraFx`: trauma-based shake (`AddShake`; smooth seeded noise, offset is trauma^`power`, so small hits stay small) and a field-of-view kick (`KickFov`), sampled each frame into `CameraFxOffsets` (yaw, pitch, right, up, `fov_scale`); `SetIntensity(0)` is the accessibility off switch. `ApplyCameraFx(offsets, cam)` (in `scene_renderer.h`) adds them to a `CameraState` after the game sets it from the player; `CameraState::fov_scale` (0.5..1.5) scales the 62 degree field of view. No roll yet (it would touch the view matrix and the sky basis).
  - Particles (`gfx/particles.h`, headless and tested; `CameraState::particles`): a game owns a `ParticleSystem`, adds emitters (`EmitterParams`: rate and `Burst`, life, speed, a launch cone, gravity, drag, size and RGBA over a life, spin, optional collision with the level's walls, the floor at `floor_y` and the ceiling), moves them, calls `Update(dt, &level)` and passes `Collect(...)`'s `ParticleSprite`s to the renderer. The simulation is deterministic from the seed; new particles start after a step, not aged by it; `RemoveEmitter` lets live particles drain. `DrawParticles` (after the world, before the glass; not in the mirror) builds camera-facing quads on the CPU (no instancing, so no new GL entry points beyond `DepthMask`), depth-tested but not depth-written, translucent ones sorted far to near, `ParticleBlend::kAdditive` ones (sparks, fire) drawn after; the shape (soft, spark, smoke) is made in `particle.frag`, and sprites fade near the eye. Sprites are unlit display-space colours: the game tints them for the light where they stand. At most `CameraState::kMaxParticles` (8192) draw per frame.
  - Debug tools (headless and tested except the drawing calls): `core/cvar.h` is `CvarRegistry`, typed variables (bool, int, double, custom) bound by pointer and read or written as text by name (case-insensitive, clamped), commands, a quoted command line (`Execute("name")` shows, `"name value"` sets), completion, `help` / `list` / `find`, and `Revision()` (counts changes, so a game re-applies its settings). `RegisterSettingsCvars` (`ui/settings_cvars.h`) makes one variable per `ToKeyValues` key, so every setting, and any added later, is reachable by the name it has in settings.txt. `ui/debug_console.h` has `DebugConsole` (typing, UTF-8 backspace, history with a draft, tab completion, a capped log, scrollback) and `FrameHistory` (240 frame times: fps, average, worst); `ui/debug_overlay.h` has `DebugOverlayOptions` (`debug.stats`, `debug.graph`, `debug.fly` through `RegisterDebugCvars`) and `DrawDebugOverlay` (stats, frame graph and console on the overlay surface; draws nothing without a font). `SceneRenderer::Stats()` is the last frame's `RenderStats` (`gfx/render_stats.h`: draw calls and triangles, shadow draws and faces, lights, shadow casters, particles, mirror; counted in `DrawTris`, the shadow cubes apart). `PollInput` reports the console keys in `InputPoll::console` (the ` key or F12 always, so a dev build can open it; text and editing keys only after `SetConsoleCapture(window, true)`, which also stops the game's keys and held movement). `world/free_cam.h` is `FreeCamera` (fly along the view, rise, run, mouse look), applied with `ApplyFreeCam`. The game decides whether the console exists at all (a shipping build simply ignores `console.toggle`).
  - Skeletal animation (`gfx/skeleton.h`, headless and tested): `Skeleton` (at most `kMaxBones` = 64 bones, parents before children, inverse bind matrices rebuilt from the bind pose), `Clip` (per-bone translation / rotation / scale keys; loop or clamp), `SamplePose`, `BlendPoses`, `SkinMatrices` (model space times inverse bind: what the shader takes) and `Animator` (one clip with a crossfade to the next) and `gfx/anim_state.h` `AnimStateMachine` (named states playing clips, bool / float parameters, transitions in the order added with `AnimCondition`s, `from` = `*` for any state, `when_finished` for a one-shot clip, a crossfade each; one transition per `Update`, so put a one-frame trigger's transition first). glTF clips all load looping: a game sets `Clip::loop = false` on its one-shots. `gfx/gltf.h` (`LoadGlb` / `ParseGlb`, headless and tested) reads a skinned `.glb`: the first skinned mesh node becomes skinned `Batch`es (a batch's texture is its material's name; `GltfModel::base_colors` has its colour), its skin a `Skeleton` (a synthetic "armature" root carries the transform of non-joint ancestors), every animation a `Clip`; no external buffers, sparse accessors or morph targets. GPU skinning: a `Batch` with `skin` (`SkinWeights`, one per vertex) uploads as one uncullable chunk with a 64-byte vertex (attributes 3 and 4, `aJoints` / `aWeights`); `ModelInstance::skin` is the instance's bone matrices, uploaded into the `uBones[64]` uniform array with `uSkinned = 1` in the world program and, swapped in `scene_shadows.cpp`, the shadow program (the instance's skin is part of a lamp cube's cache key). Static models draw exactly as before. The character shipped is `assets/characters/prototype_pete.glb` (KayKit, CC0, 30 clips: Idle, Walk, Run...).
  - AI (`world/ai.h`, headless and tested): `ai::` behaviour tree (`Leaf`, `Condition`, `Sequence`, `Selector`, `Inverter`, `Succeeder`, `Cooldown`; reactive, re-evaluated from the first child each tick; leaves are the game's callbacks) and perception (`CanSee`: a cone over `Level::LineOfSight`; `CanHear`: loudness against distance, doubled behind walls). `world/nav.h` is the A* and reachability.
  - Triggers and rules: `world/trigger.h`, `core/events.h`, `world/event_graph.h` (`EventGraphRuntime::Load(level)`, `Sample`, `Dispatch`); the editor edits both (`DrawTriggers`, `DrawRules` in `ui_panels.cpp`; `RenameTrigger` and `RemoveTrigger` in `editor/level_doc.h` keep the rules driven by a trigger in step, `NewRuleId`).
  - Save files (`data/save.h`, headless and tested): `SaveData` (a version and named JSON sections), `SaveSlots` (`<dir>/slot<N>.json`, atomic writes), `SaveFromText` with a migration list (`migrations[i]` upgrades version i+1; a newer file is `kTooNew`). `world/save_state.h` has `ProgressToJson` / `ProgressFromJson` and `PlayerToJson` / `PlayerFromJson`; a game adds its own sections (doors, `Level` diffs, NPCs).
  - Input actions (`ui/input_map.h`, headless and tested): `InputMap` of named actions in contexts with up to two `Binding`s each (`key:W`, `pad:South`, `axis:LeftX-`, `mouse:Left` as text), conflicts only inside a context (`Rebind` refuses or steals), `ToJson` (differences only) / `FromJson`, and `ApplyDeadZone`. `ActionTracker` samples a context each frame through a `BindingProbe` (strength, `Down` / `Pressed` / `Released`); `DefaultGameplayMap()` is the usual first-person keys (context `kPlayContext`; names are SDL scancode names). Platform side (`platform/input.h`): `ProbeBinding` (keys, mouse buttons, pad buttons and axes), `ApplyActions` (overwrites the movement keys and interact fields of a poll, so rebound keys drive the game; analog stick walking and mouse look stay PollInput's) and `InputPoll::pressed` (the last key, mouse or pad button pressed: what a "press a key" rebind captures). Bindings are saved by the game as `InputMap::ToJson` in its own file (the template uses `bindings.json`); not in settings.txt. The rebind page is `ui/controls_ui.h`: a game keeps a `ControlsState`, calls `UpdateControlsPage(map, context, state, ui, poll.pressed)` each frame (up / down select, left / right pick the slot, confirm starts "press a key" and the next `InputPoll::pressed` becomes the binding, taking it from another action of the context and naming it in `state.note`; the confirming key itself is not taken; pause cancels a capture or leaves; a reset row and a back row follow the actions) and saves the map when it returns `kChanged`, leaves on `kBack`; `DrawControlsPage(canvas, theme, map, context, state, time)` draws it with the settings page's `MenuTheme` and registers hotspots (row, and slot as the value). Action names come from `Tr("controls.<action>")`; the built-in strings cover the default map's actions in English and Greek. `BindingLabel` is how a binding reads. The settings menu reaches it: a game sets `GameSettings::controls_page` (not saved) and the main page gains a `kSetControls` row (`SettingsPageItems(page, controls)`) that switches `SettingsPage` to `kControls`; the menu then leaves that page alone (`UpdateSettingsPage` returns false, `DrawSettingsPage` draws nothing), the game runs `UpdateControlsPage` / `DrawControlsPage` and calls `LeaveControlsPage(page, index)` on `kBack`.
  - Sound space (`audio/spatial.h`, headless and tested): `ComputeOcclusion(walls, closed_doors)` (gain and a muffle 0..1), `MuffleCutoffHz` / `LowpassCoefficient` (a one-pole low-pass), `ReverbForRoom(cells)` (send and decay), `audio/reverb.h` `Reverb` (a small stereo Schroeder reverb: four damped combs and two all-passes a side, the combs' feedback set for a 60 dB decay time, send and decay eased, a block processed in place, untouched when the send is 0 and no tail is left; headless and tested) which `AudioEngine::SetReverb(send, decay_seconds)` runs over the whole mix before the limiter and `MixerGroups` (volume per group and ducking one while another is active; `ClearActive`; `AudioEngine` owns one: every sound has a group, "effects" for `Play`, "ambience" for loops and `AddSource`, "voice" for spoken lines, or the name given; each block the mixer marks the groups that are playing as active, updates the ducks and multiplies each sound by its group's gain, on top of `SetVolumes`; `SetGroupVolume`, `AddGroupDuck`). `world/sound_path.h` `CountSoundBlockers(level, from, to)` counts the wall and closed-door cells between a source and the listener. `AudioEngine::SetSourceMuffle(id, muffle)` low-passes a positional source (eased, per source); the template feeds it from the two calls above, and the reverb from `RoomDoors::RegionSize` of the player's room through `ReverbForRoom`.
  - Layered music (`audio/music.h`, headless and tested): `LayerFader` fades named layers to targets (`Fade`, `Crossfade` to a new set, `Update(dt)`, `Gain`, `Wanted`, `Silent`). `AudioEngine::StartMusic(layers)` starts the loops together and silent so they stay in step (a voice with `music` set, group "music", which `PlayLoop`'s ambience crossfade leaves alone), `SetMusicLayer(layer, gain, seconds)`, `CrossfadeMusic(layers, seconds)` and `StopMusic(seconds)` (the layers fade out, then the voices are retired); music follows the ambience volume and the voice duck. The layers should be loops of one length. The template fades a layer in when the player is in the back room.
  - Sun and day/night (`gfx/sky.h`, headless and tested): `SkyAt(hour)` is a `SkyLook` (direction toward the sun or moon, its light colour with intensity, ambient, zenith / horizon / fog colours, star visibility, sun-or-moon disc, cloud brightness) from keyframes through the day, continuous and wrapping; `NightLook()` is the engine's old fixed night (the moon at `{0.148, 0.417, -0.897}`, light `{0.165, 0.209, 0.319}`). `CameraState::time_of_day` (hours; negative, the default, is `NightLook`) applies to an `outdoor` scene only: `Frame::sky` feeds `uMoonDir` / `uSunColor` / `uSkyAmbient` (world shader) and `uZenith`, `uHorizon`, `uSunLight`, `uStars`, `uSun`, `uCloudLight` (`night_sky.frag`) and the fog colour. With it off the values equal the old constants (a float rounding of the folded `0.30 * 0.55` aside). Sun shadow (`CameraState::sun_shadow`, off by default): `gfx/sun_shadow.h` `ComputeSunShadow(eye, to_light, half_extent, depth_range, map_size)` (headless, tested) gives the orthographic light view and projection of a box centred on the viewer, its centre snapped to whole texels in all three light axes (no shimmer, and a stable cache key); `core/mat4.h` has `Mat4Ortho`. `SceneRenderer::DrawSunShadow` (after `DrawShadows`; `scene_shadows.cpp`) draws the scene into `sun_target_`'s depth texture (2048 x 2048, 48 m across, 80 m deep) with the shadow program and `ModelInstance::kShadow`, only when the scene, the snapped box or a caster changed; `world_lighting.frag`'s `sunShadowFactor` (3x3 PCF, normal offset 5 cm, a fade at the box edge, texture unit 9) multiplies the outdoor light and its specular. Outdoor scenes only, and the Shadows setting at 0 turns it off. One map, no cascades: shadows are of what is within 24 m.
  - Instances, cull and LOD (`gfx/lod.h`, headless and tested): `PlanDraws(requests, lods)` drops instances beyond their `max_distance` or with no model, swaps a model for its `ModelLods` far model beyond a distance (`SceneRenderer::SetModelLod`; chains allowed, loops cut) and stable-sorts the rest by model so `draw_state_` rebinds less. `DrawInstances` plans per pass from the camera's eye; the shadow pass is never culled or swapped. `ModelInstance::max_distance` is the cull. GPU instancing: in the planned (model-sorted) list a run of two or more instances of one model with no skin is one instanced draw per batch (`DrawArraysInstanced`, `SceneRenderer::SetInstancing(false)` turns it off for comparison; the picture is the same). The matrices go up in one dynamic buffer (`instance_vbo_`, 16 floats each) read as attributes 5..8 (`aModel`, divisor 1, set on every world VAO by `SetInstanceLayout`; a non-instanced draw ignores them), and `world_geometry.vert` takes `aModel` when `uInstanced` is 1, else `uModel` (the shadow program swaps its own `u_instanced_` like `u_skinned_`). `DrawTris` counts an instanced draw as one draw call and `count / 3 * instances` triangles. Skinned instances still draw one by one (their bones are per instance). Baked world geometry is one VBO per texture already and is not instanced.
  - Hot reload, for development (5.3): `core/file_watch.h` `FileWatcher` (polls files and folders by modification time and size on an interval, headless and tested; `Add` takes the baseline, `Poll(dt)` returns what was added, changed or removed). `SceneRenderer::ReloadShaders(dir)` rebuilds every program from the loose GLSL under `dir` (the generated `shaders::kShaderFiles` table maps each embedded string to its path; `MYTHOS_ENGINE_SHADER_DIR` is the engine's folder); a program that fails to compile keeps its old one, so a typo does not blank the screen, the error is logged and it returns false. `SceneRenderer::ReloadTextures(lib)` uploads the library again into the GL textures already there (ids that uploaded geometry holds stay valid; a new `_nrm` / `_rough` / `_metal` / `_ao` companion needs `UploadWorld` again). Models: `ModelLibrary::LoadFile(path)` reloads one `.obj` (a file that does not parse keeps the old model), `SceneRenderer::ReplaceModel(id, batches)` swaps an uploaded instance model in place, and baked furniture needs `UploadWorld` again. Sounds: `AudioEngine::LoadDir(dir, {name})` again replaces a clip in place under the stream lock (a playing sound carries on). A level is the game's to reload (the template's `Game::ReloadLevel`: parse into a copy, swap only on success); the template also reloads models and sounds from the engine's folders. Shipping builds simply do not watch.
  - Prefabs (`editor/prefab.h`, headless and tested): `Prefab` (a footprint and furniture / decor cells relative to its top-left corner) in a `.prefab` text file that mirrors the level format (`[size]`, `[furniture]`, `[decor]` lines; `;` comments), `ParsePrefab` / `SerializePrefab`, `CapturePrefab(doc, x0, y0, x1, y1, name)`, `Rotated(prefab, quarter_turns)` (clockwise on the map: cells, footprint, yaw - 90 and offsets turn together) and `PlacePrefab(doc, prefab, x, y, turns, blocked)` (skips items off the map, furniture on a refused glyph or an occupied cell). A placed prefab is ordinary level items: editing them afterwards is the override, nothing links back to the file. The editor's Inspector has a Prefabs section (`DrawPrefabs`: save a rectangle to `<project>/assets/prefabs/<name>.prefab`, place one at a cell with a turn); a game needs no code.
  - Cutscenes (`world/cutscene.h`, headless and tested): a `Cutscene` is camera keys (`CameraKey`: position as x / eye height / z, yaw, pitch, fov scale, and the `Ease` of the move into it), cues (`CueKey`: an `EventAction`, the rules' type and argument, for the game to carry out), named value tracks (`ValueTrack`: a fade, an actor's position; whatever the game reads) and animation keys (`AnimKey`: actor, clip, fade); a text file (`ParseCutscene` / `SerializeCutscene`: `duration`, then `[camera]`, `[cues]`, `[values]`, `[anims]` lines; keys in any order; `EaseName` / `ParseEase` are the easing names). `CutscenePlayer` (not owning the scene) `Update(dt, on_cue, on_anim)` fires each key once, in time order (a key at 0 on the first update), holds the last camera and values at the end, and `Skip` jumps to the end firing every key not yet fired, so a skipped scene still sets its flags. `Camera(&sample)` and `Value(name)` sample the tracks (yaw turns the short way). Builds on `core/tween.h` easings and `core/events.h` actions; the game decides what a cue, an actor or a value means. `SortCutscene` and `ValidateCutscene` (problems one line each) back the editor's Cutscene panel (View > Cutscene, `DrawCutscenes` in `ui_panels.cpp`): files in `<project>/assets/cutscenes`, tables for camera keys (with "Add key from the viewport camera": the orbit camera's eye, heading as yaw, pitch negated), cues, value tracks and animation keys, the problems, and "Sort keys and save" (disabled while there are problems).
  - Ambient occlusion (SSAO, `CameraState::ssao` 0..1, the Ambient occlusion setting `ambientOcclusion` in settings.txt, off by default): `RenderTarget` now has a depth *texture* (always attached; the scene target's depth is no longer a renderbuffer) and `SetResolveDepth(true)` makes `Resolve()` copy the multisampled depth into it (only while SSAO is on). `SceneRenderer::BuildAo` (before bloom in `Composite`) runs `ssao.frag` at half size (view-space position from the linearised depth, the normal from the closer neighbours, a 12-point ring above the surface rotated per pixel by interleaved gradient noise, `uRadius` 0.7 m), blurs it with the bloom blur (`ao_a_`, `ao_b_`), and `lens_and_fxaa.frag`'s `applyAo` multiplies it into the picture, less where the pixel is already bright (it stands in for the ambient term only, since the picture is already lit and tone mapped). With `ssao` 0 nothing runs and the picture is unchanged. Not done: occlusion in the mirror view, and applying it to the ambient light inside the world shader.
  - Baked light (`gfx/probes.h`, headless and tested): `BakeProbes(level, lamps, options)` makes a `ProbeGrid` (RGB per probe over the floor plan, `spacing` 0.5 m by default, probe (i, j) at `((i + 0.5) * spacing, (j + 0.5) * spacing)`) from static `ProbeLamp`s: a lamp lights a probe when `Level::LineOfSight` is clear, with the renderer's own `(1 - d / radius)^2` falloff times 0.7 for the average surface angle, plus an optional baked ambient; probes inside walls take the mean of their lit neighbours (two passes) so sampling at a wall is not black; `Sample(x, z)` is bilinear; `SerializeProbes` / `ParseProbes` are a text file. `SceneRenderer::UploadProbes(grid)` puts it in an RGBA16F texture on unit 8 and `world_lighting.frag` adds `uProbe.z * texture(uProbeTex, vWorld.xz * uProbe.xy)` to the direct light before the lamps (`uProbe` is 1 / extent in x and z, and the strength; `CameraState::baked_light` 0..1 scales it, 0 or no upload = off, pixel-identical). A game bakes the lamps that never move and leaves them out of `CameraState::lights`: no 32-lamp limit or per-pixel cost for them, but no shadows, no flicker, no normal-dependent shading (one colour per spot, at the floor plan only: no heights, so stacked floors share a grid). Not done: probes in 3D, spherical-harmonic direction, the mirror, a bake tool in `tools/`.
  - Reflection probes (`CameraState::reflections` 0..1, off by default): `SceneRenderer::AddReflectionProbe(x, y, z)` (up to `kMaxReflectionProbes` = 4; `ClearReflectionProbes`) registers a capture point. `DrawReflectionProbes` (after the shadow passes, before the mirror) picks the probe nearest the viewer and, when it is new or the scene changed (`SceneKey` plus its position), draws the world six times through the usual `DrawWorld` into a 128 x 128 RGBA8 `ReflectionCube` (`gl_objects`: a cube texture with mips, its own framebuffer, a shared `DepthBuffer`; seamless cube filtering is enabled) with a camera copy that has no instances, glass, particles, hand light, mirror or sun shadow and a frame with no vignette or grain, then `BuildMips()`. The world pass (`capturing_probe_` off) binds it on unit 10 with `uEnv` (strength, highest mip) and `environmentSpecular` in `world_lighting.frag` mixes `textureLod(uReflectionEnv, reflect(-v, n), roughness * maxLod) * 0.8` over the analytic ambient-times-sky guess. The capture is of display colours (already tone mapped) and has no parallax and no sky; only the probe nearest the viewer is used. Off: no capture, the old reflection.
  - Template game: `template-game/` (see its README) is a small complete game on the engine, built and tested with it; see the rule at the top of this file.
  - Colour textures are uploaded as `SRGB8_ALPHA8` (the shader gets linear values from sampling, no `pow`); normal maps stay `RGBA8`.
  - Thin walls and windows: a `TileInfo::thin` solid cell is a post of `kThinWallThickness` (0.2 m) at the middle of the cell plus an arm to every solid or door neighbour (`Level::ThinArms` / `ThinRects`, used by both the mesher and collision, so what you see is what blocks you); the strips of the cell either side of the slab get the floor and ceiling of the room beside them (`AddThinWallCell`, quarter by quarter, taking the room diagonally across when both edge neighbours are wall). `Level::BoxBlocked` / `PointBlocked` are the precise tests (`CanOccupy` and `LineOfSight` use them); `Passable` stays whole-cell. A `window` tile is a thin wall with a sill, jambs, a frame and a glass quad of the texture `glass` (the game supplies it). A door cell takes the thickness of the wall it is in; `RoomDoors` swings a door into the side that runs further straight on from it (a room is deeper than a corridor), the smaller region on a tie. `CameraState::lightning` (0..1) adds a cold flash to the ambient light of the world shader and to the sky.
  - Floors stacked in one scene: `kFloorPitch` (2.51 m, a hair above `kWallHeight`, so a ceiling and the floor over it never share a plane); `BuildSceneGeometry(level, models, outdoor, y)` raises a floor, `AppendSceneGeometry` joins them, tile flags `openCeiling` / `openFloor` (no ceiling / no floor: a stairwell), `DoorInstance::y`. Lightning: `CameraState::lightning` is ambient light in `world_lighting.frag` and the sky in `night_sky.frag`; with `lightning_zoned` the world's part is limited to up to `kMaxLightningZones` boxes (`LightningZone`, uniforms `uZoneCount/uZoneXZ/uZoneY`), none at all lighting nothing.
  - Mirror glare: `MirrorState::flare` (0 off) adds the hand light's glare to the mirror glass in `mirror_glass.frag`: the spot where the beam strikes the glass plane, an anamorphic streak and two ghosts through it, and the glint of the light's reflection (its image behind the glass, seen from the eye). The light is at the hand origin below, warm for the torch and orange for the lighter.
  - Hand light origin: `CameraState::hand_origin_set` with `hand_x/y/z` makes the torch's cone and falloff start at that world point (the torch's tip) and its shadow cube be cast from there (`uHandOrigin` / `uHandPos` in `world_lighting.frag`); unset, the beam starts at the eye as before.
  - Shadow casters: a `ModelInstance` with `views` including `kShadow` is drawn into the shadow cube maps of the lamps and the hand light; the cache key of a lamp's cube includes the casters within its reach, so a moving one redraws that cube and nothing else does. `AddBodyInstances(..., casts_shadow)` puts the player's figure there (it is seen only in the mirror).
  - Model instances and the mirror: `UploadModel(batches)` returns an id; a frame's `CameraState::instances` draws those models at the matrices the caller gives (`ModelInstance`: `views` = `kMain`, `kMirror` and/or `kShadow`). They are drawn in the main pass and the mirror pass, and into the shadow cubes only with `kShadow` (a torch in the hand must not shadow its own light; the player's body does). `CameraState::mirror` (`MirrorState`: glass centre, horizontal normal, half size) turns on one planar mirror: `DrawMirrorView` draws the world again into `mirror_target_` (3/4 size) with the view reflected about the glass plane (`view * R`; the lighting stays real, lamps and the eye are not moved) and `uClip` (world shader) dropping everything behind the plane plus 1.5 cm, which removes the wall and the mirror prop's own face; `DrawMirrorGlass` then lays a quad over the glass that samples that target by screen position (`mirror_glass.vert/.frag`), tinted and slightly translucent. It runs only when the glass faces the eye and is in the frustum.
  - Tools for models: `tools/mythos_models.py` is the Poly Haven glTF to OBJ conversion (`Spec`: scale, roll / pitch / yaw, `glass=False` drops BLEND materials, `cutout=True` bakes MASK / BLEND leaf cards to a PNG with alpha as a `cutout_<texture>` material (alpha-tested), `art=` shows a game texture on an `_artwork` material, per-model `size`, `skinned=True` keeps a rigged model as one `.glb` in `assets/characters/` (`pack_glb`: the buffers joined, images and textures dropped, skins and animations untouched; nothing rotated or scaled; `python3 tools/test_mythos_models.py` tests it); `run` is the command line; `configure` the target repo) and `tools/fetch_cc0_models.py` the engine's list. Run the fetch tool for every model, never with `--only`, before committing: CREDITS.md and `model_credits.json` are rebuilt from the run. A tool that needs the engine checkout: `MYTHOS_ENGINE_DIR`.
  - Common models: besides the baked scans, `tools/generate_models.py` writes the procedural stand-ins in `mythos_assets.COMMON_MODELS` (curtain, rug, lamp_floor, lamp_table, workbench, shelving, bench, coatrack: plain boxes, placeholders to swap for a scan of the same name; a Poly Haven OBJ is left alone). The list of scans also holds cabinet, dresser, stool, crate, winebottles, ladder, pillows, schooldesk, grandfather, toolchest and deskamp, and the scans moved over from the first game: plant, shoes, hat, oillamp, lamppost, hammer, handplane, tape, duck and cake. Only CC0 goes in the engine: a CC BY model (Sketchfab) stays in the game that credits it.
  - Basic models: `assets/models` + `assets/modeltex` ship the basic models of houses and offices (furniture, household things, picture frames, a torch, a plant, boots, a hat, an oil lamp, a street lamp, a mason's tools, a cake, a duck), baked from Poly Haven by `tools/fetch_cc0_models.py` through `tools/mythos_models.py` (the conversion a game's own fetch tool reuses; `assets/data/model_credits.json` is what a game lists on its credits page). The picture frames show the `painting` texture: a game overrides it with its own art. A game's assets are laid over these, so a model of the same name replaces one; a game's generator must not write a procedural model of a name shipped here (the `GENERIC_MODELS` builders are the fallback).
  - Blending, mist and glass: a model material `blend<percent>_<texture>` sets `Batch::opacity` and is drawn in a second pass after the solid scene (no shadow); `cutout_<texture>` sets `Batch::alpha_test`. `CameraState::mist` / `mist_height` is ground mist in the lighting shader; `CameraState::glass` (`GlassPane`, `drops` for beads of water) draws tinted blended panes every frame with a sky reflection (`glass_pane.vert/.frag`); `PointLight::halo` (0..1, uniform `light_halo`) is how much of a lamp's light the fog scatters to the eye, 0 for a light that only lights (a window's).
  - Input: `PollInput` also gives analog walking (`MoveInput::analog_forward/side`), gamepad rumble, light bar and a last-device-used flag. `FindAimed` backs off up to 1.5 m from a target so one on furniture against a wall stays reachable.
  - Levels: besides `[furniture]` (solid, one cell; a line may end with `offX offZ lift` to push a piece against a wall), a `[decor]` section of `x y model yaw [offX offZ lift]` lines places non-solid pieces (a vase on a table, a frame on a wall); `tools/mythos_assets.py write_level(..., decor=)` writes it and the level editors keep it as they find it.
  - Normal mapping: every texture gets a normal map made from its own brightness (`gfx/normalmap.h`, strength `kNormalStrength` in `scene_renderer.cpp`), bound on unit 6. The world shader builds the tangent frame from screen-space derivatives (the vertices carry no tangents) and bends the normal for lamp, moon and hand-light lighting only; shadow bias still uses the true normal.
  - PBR, metallic-roughness (`gfx/pbr.h`): a texture `X` may have companions `X_nrm` (tangent-space normal, glTF +y up), `X_rough`, `X_metal` and `X_ao` (greyscale, green channel read), registered like any texture and not drawn on their own. `MakeSurfaceMap` packs the normal (authored, else brightness-made) and gloss (alpha = 255 - roughness; 0 = matt) into unit 6; `MakeMaterialMap` packs R metal, G occlusion into unit 7 (one shared default 1x1 texture for the many textures with neither). The world shader: GGX / Schlick-Smith / Fresnel specular for the lamps, moon and hand light (F0 0.04, or the albedo for a metal, which has no diffuse), baked occlusion dimming the ambient term, and reflections of the era's ambient light (no probes; Karis' analytic environment BRDF, specular occlusion). A surface with no companion renders pixel-identically to before. The `materials` setting (`CameraState::materials`, uniform `uMaterials`): 0 off (no specular, metal or occlusion), 1 basic (no environment reflections), 2 full; saved as `materials` in settings.txt.
  - Lamps: `CameraState::lights` takes up to `CameraState::kMaxLights` (32) point lights a frame; the arrays in `world_lighting.frag` are that size (keep them equal), and the cost grows only with how many are given. Only the nearest lit ones cast shadows (below).
  - Shadows: the nearest lit lamps (1 to 4 by level) and the hand light each have a cube map of distances (`ShadowCube`, sharing one `DepthBuffer`). A cube face is redrawn only when its lamp or the scene (geometry revision, scroll, doors) changes (keys are kept per face); the hand light draws only the faces its cone can reach (`hand_faces_`, mirrored by the shader's `uHandFaces`, which treats undrawn faces as unshadowed, so keep the cone cosines in `ChooseLamps` and the shader in step): bump `scene_revision_` when a new kind of upload changes what casts shadows, and add anything that moves to `SceneKey`. The settings' counts (`kShadowLevelCount`, `kRenderScaleLines`, `kAntiAliasSamples`) live in `settings.h`; the renderer reads them, so keep new levels there.
  - Settings: `settings.h` (values, pages, persistence), `settings_ui.h` (`DrawSettingsPage`, `MenuTheme` holds every layout number), `platform/apply_settings.h` (applies them to window, renderer, mixer, camera), and built-in English and Greek strings in `engine_strings.cpp`, which `Tr()` falls back to. A new setting is added here only; the game just picks up the row.
  - JSON loaders for shared formats: `LoadAchievementDefs`, `LoadPlayerParams`, `LoadSoundBank`, `LoadTranslation`, `LoadCredits`, `LoadFontFiles`.
  - The context is OpenGL 4.1 core with `#version 410 core` shaders: the ceiling on macOS. Don't use 4.2+ features (compute, SSBOs, `glBufferStorage`, DSA) without a fallback.
- Third-party code: `stb_truetype` (fonts) and `stb_image` (texture overrides: PNG, BMP, TGA, JPG; vendored in `third_party/stb`), plus nlohmann/json 3.12.0 and GLM 1.0.3, which CMake takes from an installed copy or fetches (`FetchContent` in `CMakeLists.txt`; bump the version there and in the `find_package` line). nlohmann/json is a public dependency of `mythos::engine` (it is in `json.h`); GLM is private.
- **`mythos::sdl_main`**: interface target for SDL_main.h; `MYTHOS_EXE_KIND` (set to the parent scope) picks WIN32 / MACOSX_BUNDLE / plain for game executables.

Folders of `src/engine/` (include as `"engine/<folder>/<file>.h"`); a folder may include only the ones to its left in this order, so there are no cycles:

- `core/`: `math`, `mat4` (matrices through GLM, frustum, cube-face views, `Mat4Ortho`), `tween`, `events` (rules), `cvar`, `file_watch`, `noise`, `json` (nlohmann `ordered_json` as `json::Value`, plus a strict `parse` that rejects duplicate keys) and `json_reader`, `fileio`, `vfs`.
- `world/`, `audio/`, `data/` (each depends on `core/` only): `world/` is the grid world and first-person rules (`level`, `tiles`, `movement`, `player`, `ai`, `nav`, `trigger`, `event_graph`, `cutscene`, `sound_path`, `save_state`, `body` (pose of the figure and the light in its hand: `PoseBody`, `TurnBody`, `SolveArm`, `BodyParams` / `HeldParams`, and the hand's motion: `HandSway`, `BodyMotion`), `mirror` (`PlaceMirror`: where a prop's glass stands and whether it is seen), `room_doors`, `interact`); `audio/` the sound arithmetic and the sound bank (`audio_math`, `spatial` (occlusion, mixer groups), `reverb`, `sound_bank`, `radio_fx`: `RadioFm`, the glitching FM radio the mixer puts a `PlayVoice(..., radio=true)` line through); `data/` the shared data formats and localisation (`save`, `achievements`, `credits`, `i18n`, `translation`, `engine_strings`).
- `gfx/` (core, world): the CPU side of graphics (`surface`, `textures`, `materials`, `mesh`, `model`, `skeleton`, `anim_state`, `gltf`, `sky`, `sun_shadow`, `probes`, `lod`, `normalmap`, `pbr`, `font` (the 5x7 bitmap font), `text` (SDF text layout), `flicker`).
- `ui/` (data, gfx): `input_map`, `controls_ui`, `ui` (overlay boxes, text, hotspots), `paging` (PaginateText, PaginateEntries, WrapLines, WrapWords, ClampPage), `menu`, `settings`, `settings_ui`.
- `editor/` (core, world, gfx): the level editor's headless rules (`level_doc`, `prefab`, `project`, `history`, `adapter`).
- `platform/` (everything above, and SDL / GL): `window`, `input`, `audio`, `app`, `apply_settings`, `platform/editor/` (the level editor's window and panels, on Dear ImGui), and `platform/gl/` for the renderer (`gl_api`, `gl_objects`, `body_instances` (upload the body / torch / lighter models, add a pose's instances), `scene_renderer` with `scene_shaders` and `scene_shadows`, `text_renderer`).

The engine supplies mechanisms and a game supplies meaning: games own a `Level`, `Player`, `PlayerWalker`, `RoomDoors`, `Interactor`, and a `Progress`-derived state, and turn `Use` outcomes (`interact.h`) into text, sound and plot. Prop texts are translation keys resolved through `Tr("dotted.key")` (`i18n`); the engine never holds story strings.

**The level editor** is native: `MythosEditor` and the `mythos::editor` library (option `MYTHOS_BUILD_EDITOR`, on when the engine is top level; Dear ImGui with docking is fetched at `MYTHOS_IMGUI_TAG`). Furniture is placed freely in its cell (`SetPose` keeps `off_x`, `off_z` and `lift` for furniture as for decor; collision stays by cell). It is generic: it knows the level files (`[map]`, `[furniture]`, `[decor]`, the `map_editor` stamp generators look for) and the tile legend, and nothing of any game. A game's things come through `mythos::editor::Adapter` (`src/engine/editor/adapter.h`): the JSON files it edits (`DataFiles`, held as a `DataSet` the editor loads, saves, snapshots for undo and tracks as dirty), entity kinds from `kFirstGameKind` up (`Entities`, `Describe` -> a `Visual` the viewport draws, `GetPose` / `SetPose`, `Label`, `Data` for the Inspector, `Duplicate`, `Remove`), the levels (`Info`, `Contexts`, `Stack`), `SetupTextures`, and the preview (`GameExecutables`, `PreviewOptions`, `Preview` builds the command line and may edit its copy of the data). It must never name a game, a game's files or a game's binary; a game's `main()` calls `RunEditor` with its adapter. Layers: `src/engine/editor/` (`level_doc`, `project`, `history`, `adapter`) is in `mythos::engine` (no SDL, GL or UI, unit-tested in `tests/test_main.cpp` with a fake adapter); `src/engine/platform/editor/` (`viewport`: the editor's own small GL renderer over `BuildSceneGeometry`; `editor_app` and `ui_panels`: the panels and interaction; `run`: window, ImGui backends and frame loop) is `mythos::editor`, and `tools/editor/main.cpp` is the adapter-less `MythosEditor`. `run.cpp` also decides the project: `--project`, else (no arguments, as from a file manager) the folder remembered in the prefs file `project.txt`, else a native folder dialog (`SDL_ShowOpenFolderDialog`) until the folder holds `assets/levels`; textures and models come from the project's `assets/` when it has `models/`, else from the `assets/` shipped beside the editor (`BundledAssets`; a build from source has none beside it, so `MYTHOS_ENGINE_ASSET_DIR` names the folder). A startup failure shows a message box (a silent exit looks like an app that does not open). Releases are unsigned.

`tools/mythos_assets.py` is a shared Python library that game-side generator scripts import to build OBJ models (`Mesh`) and level files (`Grid`, `write_level`); its output formats must stay in sync with `model.cpp` (OBJ parser, `glow_<texture>` materials) and `level.cpp` (`[map]` + `[furniture]` sections). `materials.h` defines the common texture names every game gets via `AddCommonMaterials()`.

## Conventions that are easy to break

- Naming (Google): types `PascalCase`; functions and methods `PascalCase` (`LoadCredits`, `SceneRenderer::UploadModel`); variables, parameters and struct fields `snake_case`; class data members `snake_case_` with a trailing underscore; constants and enumerators `kPascalCase` (`Verb::kRead`, `kShadowLevelCount`); namespaces `lower_case`. Headers use `#ifndef MYTHOS_<PATH>_H_` guards (the path from `src/`), never `#pragma once`; `#include` groups are the related header, C headers, C++ standard headers, other libraries, then project headers. No `using namespace` (using-declarations are fine); no C-style casts; `int64_t` instead of `long`. Out-parameters stay non-const references (the guide's current rule).
- The GL entry points (`gl_api.h`) are declared with an X-macro whose argument becomes both the C++ name and the loaded symbol (`"gl" #name`): keep them exactly as the OpenGL name (`DeleteTextures`), or the loader looks up a symbol that does not exist (it still compiles).
- One map cell = one world unit; world x = column, z = row, y up. Model fronts face `+z`; yaw 0 faces south (+z), 90 faces east (+x). Python tooling and C++ share this.
- Room door glyphs are `N` (closed, solid) and `n` (open); a tile legend must define both as doors.
- The engine has no fail state; transitions are seamless.
- Source is UTF-8 (the built-in Greek strings, a few glyphs); MSVC builds with `/utf-8`, which is `PUBLIC` so games get it too.
- MSVC rules that GCC and clang let slide: no raw string literal containing quotes inside a `CHECK(...)` argument (hoist it into a local; it breaks stringizing), no `fopen` / `sscanf` (C4996: use streams), and no passing `float[N][M]` where `const float (*)[M]` is expected (pass a struct such as `Frustum`). CI builds with warnings as errors, so also: no `CHECK` on a compile-time constant condition (C4127: use `static_assert`), and no `long` (32-bit on Windows: C4244 on an `int64_t` argument; use `int64_t`).
- Include what you use: GCC's libstdc++ does not pull in `<cstring>`, `<cmath>`, `<algorithm>`, `<memory>` and the like the way libc++ does, so a missing header builds on macOS and fails on Linux. Include each standard header in the file that uses it; never wrap one in a platform `#if`.
- The engine ships only the assets games share: fonts, common sounds, a few textures, the basic house and office models (`assets/models`, `assets/modeltex/m_*`, `assets/data/model_credits.json`) and the roughness / metal companion maps of its common materials (`assets/modeltex/`, made by `tools/mythos_pbr_maps.py`; a game that registers its stage's `modeltex/*.bmp` as textures gets them) in `assets/` (games merge their own over them; `MYTHOS_ENGINE_ASSET_DIR` names the folder). Anything added must be CC0/OFL and recorded in `CREDITS.md`.
